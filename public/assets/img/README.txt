Place REAL photos here (your own or properly licensed), compressed for mobile (under 300 KB each):
  hero.jpg   - Civil Registration Office building or an officer at a desk (Home page cover)
  officer.jpg - Registration officer at a desk reviewing registers (About page cover)
  street.jpg - Street or civic scene in Mogadishu (Contact page cover)

The cover.jpg/cover.svg file is not a photo: it is the civic backdrop behind every page
cover band, drawn in vector so it stays sharp at any size. The photo on each page is laid
over it at reduced opacity, so the band still looks deliberate if a photo is a placeholder
or missing. Replacing a photo only means dropping a file with the same name in this folder.

Only hero.jpg is strictly required; each page shows its photo when the file exists and
falls back to the backdrop alone when it does not.
